# CNC Programmer AI (этап 1)

Android-приложение для написания УП фрезерного ЧПУ Fanuc 0i Plus.

## Сборка
1. Залейте все файлы в репозиторий GitHub (ветка main).
2. Папка `.github/workflows/build.yml` обязательна. Если она не загрузилась,
   создайте файл `.github/workflows/build.yml` вручную и вставьте содержимое `build.yml.txt`.
3. Вкладка Actions → Build APK → после зелёной галочки скачайте артефакт `CNC-Programmer-AI-debug`.

## Что есть
- Главный экран, навигация, тёмная тема
- Материалы и фрезы (стартовая база)
- Расчёт режимов: S и F по формулам
- Список операций, остальное пока заглушки
